# SPENDRA — AI Cost Optimization Platform

SPENDRA is an AI spending intelligence platform designed to help startups, teams, and developers identify unnecessary AI tool expenses, optimize subscriptions, and uncover potential monthly savings through automated audit reports.

## Live Demo

https://spendrahq.vercel.app

---

# Overview

Modern teams increasingly rely on AI tools such as:
- ChatGPT
- Cursor
- Claude
- GitHub Copilot
- Gemini

SPENDRA helps teams identify overspending, unnecessary enterprise subscriptions, and inefficient AI software usage.

---

# Tech Stack

- Next.js 16
- React
- TypeScript
- Tailwind CSS
- Supabase
- Vercel

---

# Features

- AI spend audits
- Pricing intelligence engine
- Dynamic savings calculations
- Public shareable reports
- Responsive SaaS UI
- Supabase persistence
